# AgentOnTrack website

The public website for AgentOnTrack: **https://pandeysatyam.com/agentontrack/** (`satyamamarpandey.github.io/agentontrack/` redirects there)

AgentOnTrack is a free, local-first control layer for AI coding agents. You set the goal and approve what matters, your agent does the work, and independent checks decide when it is done.

This repository holds only the built static site and the tests that run against it, before and after each deployment. The product source is in a private repository during the preview.

- **Feedback or access requests:** [open an issue](https://github.com/satyamamarpandey/agentontrack/issues/new).
- **Security reports:** [private advisory](https://github.com/satyamamarpandey/agentontrack/security/advisories/new).
- **Test evidence:** the [Actions tab](https://github.com/satyamamarpandey/agentontrack/actions) shows each test and deployment run.
