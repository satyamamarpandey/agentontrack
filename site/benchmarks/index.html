Matched live benchmark

PARTIAL: 109 of 126 planned runs, so conditions are unbalanced, and no confidence intervals are computed. Self-authored fixtures, one cheap model, one machine, a cooperative model. Not independent. Condition E was not run.

What this shows. Telling the agent the goal explains the success gap: a plain goal in CLAUDE.md (A-doc) did as well as AgentOnTrack. AgentOnTrack's added value here is stopping unauthorized effects, which native deny rules (B) also stopped in this set. AgentOnTrack used more tokens and time than the agent alone. A task can reach VERIFIED while unfinished if its check is weak.
