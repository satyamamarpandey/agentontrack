Install

Preview access: AgentOnTrack is not on npm, and its source repository is private. To try it now, ask for access with a GitHub issue. The dashboard demo on this site works with no install. With access, you need Node 24 or later and pnpm:

pnpm install && pnpm build
alias agentontrack="node $PWD/packages/cli/dist/index.js"
cd your-project
agentontrack init            # preview; add --apply to write
agentontrack install claude-code
agentontrack approver enroll # recommended: passphrase for approvals

Connect this website to your machine

The dashboard on this site can talk to the companion on your own computer. Nothing goes through this website. It is off until you ask for it, and needs a one-time code:

agentontrack dashboard --allow-public-site
# prints a pairing code; open the Dashboard link above and enter it

Your browser may ask to allow local network access: that is needed for this connection. Without that flag, use the local address agentontrack dashboard prints. Safari blocks a secure page from reaching a local address, so Safari users need that local address.

Commands

agentontrack goal set --file g.jsonApprove a goal
agentontrack goal proposals | diff | accept | rejectReview what agents proposed
agentontrack task create --file t.jsonCreate a task with acceptance checks
agentontrack approve | deny | revoke <id>Decide a request
agentontrack verifyRun the checks and record evidence
agentontrack policy profile strictRequire approval for opaque programs and reverse unauthorized file changes
agentontrack dashboardOpen the local dashboard
agentontrack doctorSee what is and is not enforced
agentontrack audit [--recover]Check the record, or recover from damage

Troubleshooting

"Refused: needs an interactive terminal". Human commands will not run from an agent's tool call. Run them in your own terminal.

"Approvals are suspended". The log failed an integrity check. Run agentontrack audit, then agentontrack audit --recover.

A task stays unverified. Run agentontrack status: it lists stale evidence, unresolved changes and test changes that need review.
