Features

What AgentOnTrack does today. Planned work is on the roadmap, not here.

Goals and tasks

A versioned goal contract with scope, exclusions and prohibited effects. Agents can propose changes; only you can accept them.

Task-bound approvals

Each approval covers one effect, for one task, goal version, policy version and runtime. They are single-use by default and expire. Unanswered requests lapse.

Effect checks

After each action the workspace is compared with what was authorized. Strict mode requires approval for opaque programs and reverses unauthorized file changes.

Evidence receipts

AgentOnTrack runs your acceptance checks itself. A task reaches VERIFIED only with current passing evidence, no unresolved unauthorized change and no unreviewed sign that tests were weakened.

A record you can check

An append-only local log with a separate witness file and an optional passphrase-protected approver key. It is tamper-evident under stated assumptions. It is not immutable.

Efficiency aids

Loop and budget limits, memory of failed commands, optional duplicate-read skipping, and compact restart context built from the record.

Local dashboard

Goals, approvals, evidence, usage and safety for your projects, paired to your browser with a one-time code.
