Local models

A model server is not an agent: it has no tools, approvals or session state of its own. agentontrack probe <url> tests what an endpoint actually does. Enforcement comes from the agent in front of it.

MCP

A local stdio MCP server exposes project state, proposals and handoffs. It has no approval, policy or shell tool. MCP is not the security boundary: the hooks are.
