Pricing

AgentOnTrack is free. There is no paid tier, and no account is needed.

What you still pay for

You bring your own agent, under your own login and plan. AgentOnTrack does not resell, pool or proxy model access. In our tests its hooks and context added some model usage on top of what the agent alone used: see the benchmarks.

What is free

  • The CLI, policy engine and evidence record
  • Agent adapters and the MCP server
  • The local dashboard

Availability

The source code is private during the preview. See the installation guide for how access works today.
